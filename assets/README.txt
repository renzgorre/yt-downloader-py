Place the following files in this directory before building the installer:

  icon.ico               — App icon (256x256 recommended, multi-resolution ICO)
  installer_banner.bmp   — Left-side banner for the NSIS installer wizard
                           Must be exactly 164 x 314 pixels, 24-bit BMP

These files are not committed to git because they are binary assets.
Generate them from your source artwork before running the NSIS build step.
